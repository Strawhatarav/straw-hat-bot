## 🔧 Utility

The Utility category provides information and useful tools for the Discord server, its members, channels, roles, and emojis.

### `/serverinfo`
Displays detailed information about the Discord server.

Planned information includes:

- Server name
- Server ID
- Server owner
- Server creation date
- Server icon
- Server banner
- Member statistics
- Channel statistics
- Role statistics
- Emoji statistics
- Server boost information
- Other server metadata

### `/userinfo`
Displays information about a Discord member.

Planned information includes:

- Username
- Display name
- User ID
- Account creation date
- Server join date
- Highest role
- Avatar
- Bot/member status
- Roles

### `/avatar`
Displays a member's Discord avatar.

### `/roleinfo`
Displays information about a Discord role.

Information includes:

- Role name
- Role ID
- Position
- Member count
- Role mention

### `/channelinfo`
Displays information about a Discord channel.

Information includes:

- Channel name
- Channel ID
- Channel type
- Category
- Position
- Creation date

### `/servericon`
Displays the current server icon.

### `/emoji`
Displays information about a Discord emoji.

# 📊 Server Statistics

Straw Hat will provide server statistics through utility commands and future server-stat features.

Statistics include:

- 👥 Total members
- 👤 Human members
- 🤖 Bot members
- 💬 Text channels
- 🔊 Voice channels
- 🗂️ Categories
- 🎭 Roles
- 😀 Custom emojis
- 🚀 Server boosts

These statistics will be read directly from Discord through the Discord API rather than manually entered into the code.
